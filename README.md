# SpawnDev.Rendusa

## Features
- A 2D and 3D media player (video, images, audio) that supports 2D to 3D on the fly conversion,  and multiple 3D input formats and output formats
- User's Media library viewer for creating playlists and managing favorites, and sources
- Media sources: drag and drop support for adding media to user's media library. 
- In browsers that support window.showDirectoryPicker(), allows adding external folders to your media library
- Uses SpawnDev.BlazorJS for Blazor WebAssembly Javsacript interop (core for many of the libraries used)
- Uses SpawnDev.ILGPU for rendering and conversion
- Uses SpawnDev.BlazorJS.TransformersJS for monocular depth estimation with DepthAnything models to allow on the fly covnersion to 3D using the generated depth to create additional views
- Some of the supported output modes: 2D, Side-by-Side, Over-Under, Anaglyph (green-magenta, red-cyan, custom), various lenticular pixel view layouts, support for additional renderers
- Some supported video and image input formats: 2D, Side-by-Side, Over-Under, Mosaic multi-view  (Ex. 4x2 grid per frame), 2D+Z (Aka: 2D plus depth)
- When playing images in a playlist they "play" for 10 seconds by default before goign to the next playlist item. Duration configurable in Rendusa Settings
- Rendusa Settings - Contains groups of settings related to specific areas of Rendusa. Things like "Image play duration", adding, removing, and configuring renderers.
- Panel that allows creating a custom renderer live in th browser by allowing writing of C# kernels in a Monaco browser component that can be tested live in the browser, showing the effects of changes on a selected input source immediately after saving the custom renderer.
- The audio player of Rendusa with show fractals visualizations that use the audios sound as a source for some of the adjustable variables the fractal viewers supports.
- The audio fractal beat viewer will be constantly animated but use the tempo ofthe audio and other information from the audio source to aid in the animation so it moves with the music
- Rendusa should support as many audio, video, and image types as possible.
- Use SpawnDev.BlazorJS.WebTorrents to include a build in torrent client that will allow streaming torrents as they download directly to our video or audio player.
- Torrents can be downloaded and the contents added to the user's media library with the user selecting the destination (can be in Rendusa's internal library fodlr or any of the user's external writable soruces, like a folder added to the lmedia library with window.showDirectoryPicker())
- Torrents can also be added to the user's media library as a 'torrent link'  where the torrent cotnents are only kept temporarily while being used to stream to one of the media players and is cleaned up when no longer needed
- Rendusa includes a tool for creating and editing a new Anaglyph renderer profile. The tool should possibly support using the user's webcam to look through each of the user's anaglyph glasses lenses and use some method to create a custom anaglyph profile that will work the best (good 3D, minimal  ghosting) for their specific glasses and display
- The renderer must have a user interface that allows  accessing all of the features a media player is expected to have
- Rendusa includes a tool specifically for creating and editing lenticular lens profiles. The tool should support using the user's webcam to analyze the display and create a custom lenticular lens profile that will work best for their specific display and lenticular lens setup. The tool should also allow for manual adjustments to the generated profile to further fine tune it for the best 3D effect and minimal ghosting.
